SQL Murder Mystery

¿Puedes descubrir al culpable?

¡Ha ocurrido un asesinato en SQL City! El SQL Murder Mystery está diseñado tanto como una lección autodidacta para aprender conceptos y comandos SQL como un juego entretenido para usuarios experimentados.

¿Nuevo en SQL?

Este ejercicio está pensado para practicar habilidades en SQL. Si nunca has usado SQL, prueba la guía paso a paso. Si buscas un tutorial completo, te recomendamos Select Star SQL.

Si ya dominas SQL, ¡puedes empezar directamente abajo!

Los detectives experimentados de SQL comienzan aquí

Ha ocurrido un crimen y el detective necesita tu ayuda. Te entregó el informe de la escena del crimen, pero lo perdiste. Recuerdas vagamente que fue un asesinato ocurrido el 15 de enero de 2018 en SQL City. Comienza recuperando el informe correspondiente de la base de datos policial.

Explorando la estructura de la base de datos

Los usuarios experimentados usan consultas para deducir la estructura de la base de datos. SQL Murder Mystery está construido con SQLite. Ejecuta este comando para ver las tablas.

Además de los nombres de las tablas, necesitas conocer su estructura. Así es como se hace en SQLite.
