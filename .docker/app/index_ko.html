SQL Murder Mystery

범인이 누구인지 밝혀낼 수 있나요?

SQL City에서 살인 사건이 발생했습니다! SQL Murder Mystery는 SQL 개념과 명령어를 자율적으로 학습할 수 있는 튜토리얼이자 숙련된 SQL 사용자가 흥미진진한 사건을 해결하는 재미있는 게임입니다.

SQL이 처음이신가요?

이 연습은 튜토리얼이라기보다는 SQL 실전 연습을 위한 것입니다. SQL을 한 번도 사용해 본 적이 없다면 가이드를 확인해 보세요. SQL을 체계적으로 배우고 싶다면 Select Star SQL을 추천합니다.

SQL에 익숙하다면 아래에서 바로 시작하세요!

숙련된 SQL 탐정은 여기서 시작하세요

사건이 발생하여 형사가 당신의 도움을 필요로 합니다. 형사가 범죄 현장 보고서를 주었지만 분실했습니다. 기억나는 것은 2018년 1월 15일에 SQL City에서 발생한 살인 사건이라는 점뿐입니다. 경찰 데이터베이스에서 사건 현장 보고서를 조회하는 것부터 시작하세요.
