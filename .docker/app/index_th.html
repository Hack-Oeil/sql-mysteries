SQL Murder Mystery

คุณสามารถค้นหาตัวคนร้ายได้หรือไม่?

เกิดคดีฆาตกรรมขึ้นใน SQL City! SQL Murder Mystery ได้รับการออกแบบมาเพื่อเป็นทั้งบทเรียนศึกษาด้วยตนเองเกี่ยวกับแนวคิดและคำสั่ง SQL และเป็นเกมที่สนุกสนานสำหรับผู้ใช้ SQL ที่มีประสบการณ์ในการไขคดีอาชญากรรมที่น่าสนใจ

เพิ่งเริ่มต้นใช้งาน SQL?

แบบฝึกหัดนี้เน้นการฝึกปฏิบัติมากกว่าเป็นบทเรียนเต็มรูปแบบ หากคุณไม่เคยใช้ SQL มาก่อน ลองดูคู่มือแนะนำ หากต้องการเรียนรู้ SQL อย่างละเอียด แนะนำบทเรียนอย่าง Select Star SQL.

หากคุณคุ้นเคยกับ SQL แล้ว สามารถ เริ่มที่ด้านล่างนี้ได้เลย!

นักสืบ SQL ผู้มีประสบการณ์เริ่มต้นที่นี่

เกิดคดีอาชญากรรมขึ้นและนักสืบต้องการความช่วยเหลือจากคุณ นักสืบได้ส่งรายงานที่เกิดเหตุให้คุณแต่คุณทำหาย คุณจำได้คร่าวๆ ว่าเป็นคดี ฆาตกรรม ที่เกิดขึ้นเมื่อวันที่ 15 ม.ค. 2018 ในเมือง SQL City เริ่มต้นด้วยการค้นหารายงานที่เกิดเหตุจากฐานข้อมูลตำรวจ

สำรวจโครงสร้างฐานข้อมูล

ผู้ใช้ SQL ที่มีประสบการณ์สามารถค้นหาโครงสร้างฐานข้อมูลได้โดยใช้คำสั่งสืบค้น SQL Murder Mystery สร้างขึ้นโดยใช้ SQLite ใช้คำสั่งนี้เพื่อค้นหารายชื่อตาราง

นอกจากชื่อตารางแล้ว คุณต้องทราบโครงสร้างของแต่ละตารางด้วย นี่คือวิธีดูใน SQLite

ที่เหลือขึ้นอยู่กับคุณแล้ว!

หากคุณเชี่ยวชาญ SQL คุณน่าจะดำเนินการต่อจากตรงนี้ได้ด้วยตัวเอง

แต่ คลิกที่นี่ เพื่อแสดงแผนผังฐานข้อมูล (Schema)

และคุณสามารถเปิดดู คู่มือแบบละเอียด ได้ตลอดเวลา
