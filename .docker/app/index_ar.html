SQL Murder Mystery

هل يمكنك معرفة من ارتكب الجريمة؟

لقد وقعت جريمة قتل في مدينة SQL! تم تصميم SQL Murder Mystery ليكون درساً للتعلم الذاتي لمفاهيم وأوامر SQL ولعبة ممتعة للمستخدمين المتمرسين لحل جريمة غامضة.

جديد في SQL؟

هذا التمرين مخصص لممارسة مهارات SQL أكثر من كونه دورة تدريبية كاملة. إذا لم تستخدم SQL من قبل، جرّب الدليل الإرشادي. إذا كنت ترغب في تعلم SQL بالتفصيل، فننصحك بدورة مثل Select Star SQL.

إذا كنت معتاداً على SQL، يمكنك البدء مباشرة أدناه!

محققو SQL المتمرسون يبدأون من هنا

وقعت جريمة ويحتاج المحقق إلى مساعدتك. أعطاك المحقق تقرير مسرح الجريمة، لكنك أضعته. تتذكر بشكل غامض أن الجريمة كانت جريمة قتل وقعت في 15 يناير 2018 في SQL City. ابدأ باسترجاع تقرير مسرح الجريمة المقابل من قاعدة بيانات قسم الشرطة.

استكشاف بنية قاعدة البيانات

يمكن لمستخدمي SQL المتمرسين استخدام الاستعلامات لاستنتاج بنية قاعدة البيانات. ولكن كل نظام إدارة قواعد بيانات لديه طريقته الخاصة. يعتمد SQL Murder Mystery على SQLite. استخدم هذا الأمر لمعرفة الجداول في قاعدة البيانات.

بالإضافة إلى معرفة أسماء الجداول، تحتاج إلى معرفة بنية كل جدول. إليك كيفية القيام بذلك باستخدام SQLite.
