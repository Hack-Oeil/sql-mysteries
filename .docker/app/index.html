SQL Murder Mystery

Pouvez-vous découvrir le coupable ?

Un meurtre a été commis à SQL City ! Le SQL Murder Mystery est conçu à la fois comme une leçon autonome pour apprendre les concepts et commandes SQL et comme un jeu captivant pour les utilisateurs expérimentés de SQL afin de résoudre un crime intrigant.

Nouveau sur SQL ?

Cet exercice est plutôt conçu pour mettre en pratique vos compétences SQL que comme un tutoriel complet. Si vous n'avez jamais utilisé SQL, essayez le guide pas à pas. Si vous souhaitez approfondir vos connaissances en SQL, nous vous conseillons un cours complet comme Select Star SQL.

Si vous êtes déjà à l'aise avec SQL, vous pouvez commencer directement ci-dessous !

Les détectives SQL expérimentés commencent ici

Un crime a eu lieu et l'inspecteur a besoin de votre aide. L'inspecteur vous a remis le rapport de la scène de crime, mais vous l'avez égaré. Vous vous souvenez vaguement qu'il s'agissait d'un meurtre qui a eu lieu le 15 janvier 2018 dans la ville de SQL City. Commencez par retrouver le rapport de scène de crime correspondant dans la base de données de la police.

Explorer la structure de la base de données

Les utilisateurs expérimentés de SQL peuvent souvent utiliser des requêtes pour explorer la structure d'une base de données. Cependant, chaque système de gestion de base de données gère ces informations différemment. Le SQL Murder Mystery utilise SQLite. Exécutez cette commande SQL pour lister les tables de la base de données.

En plus de connaître les noms des tables, vous devez savoir comment chaque table est structurée. La méthode dépend également du système de base de données utilisé. Voici comment faire avec SQLite.
