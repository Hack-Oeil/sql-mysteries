SQL Murder Mystery

Consegue descobrir quem foi o culpado?

Houve um assassinato em SQL City! O SQL Murder Mystery foi concebido tanto como uma lição autodidata para aprender conceitos e comandos SQL como um jogo divertido para utilizadores experientes resolverem um crime intrigante.

Novo no SQL?

Este exercício serve como prática de competências em SQL. Se nunca usou SQL, consulte o guia passo a passo. Se deseja um tutorial completo, recomendamos o Select Star SQL.

Se já se sente confortável com SQL, pode começar diretamente abaixo!

Detetives SQL experientes começam aqui

Ocorreu um crime e o inspetor precisa da sua ajuda. Ele entregou-lhe o relatório do local do crime, mas perdeu-o. Lembra-se vagamente de que se tratava de um assassinato que ocorreu em 15 de janeiro de 2018 em SQL City. Comece por recuperar o relatório policial na base de dados.

Explorando a estrutura da base de dados

Utilizadores experientes conseguem deduzir a estrutura da base de dados através de consultas. O SQL Murder Mystery utiliza SQLite. Execute este comando para listar as tabelas.

Além dos nomes das tabelas, precisa de conhecer a sua estrutura. Veja como fazer isso com SQLite.
