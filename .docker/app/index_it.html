SQL Murder Mystery

Riesci a scoprire il colpevole?

C'è stato un omicidio a SQL City! Il SQL Murder Mystery è progettato sia come lezione autonoma per apprendere concetti e comandi SQL, sia come gioco avvincente per utenti esperti per risolvere un crimine intrigante.

Nuovo su SQL?

Questo esercizio serve principalmente a fare pratica con le competenze SQL. Se non hai mai usato SQL, prova la guida dettagliata. Se desideri un tutorial completo, ti consigliamo Select Star SQL.

Se ti senti a tuo agio con SQL, puoi iniziare direttamente qui sotto!

I detective SQL esperti iniziano qui

È avvenuto un crimine e l'investigatore ha bisogno del tuo aiuto. Ti è stato consegnato il verbale della scena del crimine, ma l'hai smarrito. Ricordi vagamente che si trattava di un omicidio avvenuto il 15 gennaio 2018 a SQL City. Inizia recuperando il relativo verbale dal database della polizia.

Esplorare la struttura del database

Gli utenti esperti possono usare le query per scoprire la struttura del database. SQL Murder Mystery usa SQLite. Esegui questo comando per trovare le tabelle.

Oltre ai nomi delle tabelle, devi conoscere la struttura di ciascuna tabella. Ecco come fare con SQLite.
