SQL Murder Mystery

你能找出真凶是谁吗？

SQL City 发生了一起谋杀案！SQL Murder Mystery 既是一个自学 SQL 概念和命令的教程，也是一个供有经验的 SQL 用户侦破引人入胜案件的趣味游戏。

刚接触 SQL？

这个练习主要是用来练习 SQL 技能。如果你从未使用过 SQL，可以查看攻略指南。如果你想全面学习 SQL，推荐参考 Select Star SQL 等教程。

如果你熟悉 SQL，可以直接从下方开始！

经验丰富的 SQL 侦探从这里开始
