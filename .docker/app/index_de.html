SQL Murder Mystery

Kannst du den Täter finden?

In SQL City ist ein Mord geschehen! Das SQL Murder Mystery ist sowohl als interaktive Lektion zum Erlernen von SQL-Konzepten und -Befehlen als auch als unterhaltsames Spiel für erfahrene SQL-Anwender gedacht, um ein faszinierendes Verbrechen aufzuklären.

Neu bei SQL?

Diese Übung dient eher der praktischen Anwendung von SQL-Kenntnissen als einem vollständigen Tutorial. Wenn du noch nie SQL verwendet hast, probiere die Anleitung. Wenn du SQL von Grund auf lernen möchtest, empfehlen wir ein Tutorial wie Select Star SQL.

Wenn du dich mit SQL auskennst, kannst du unten direkt einsteigen!

Erfahrene SQL-Spürnasen starten hier

Ein Verbrechen ist geschehen und der Ermittler braucht deine Hilfe. Er hat dir den Tatortbericht übergeben, aber du hast ihn verloren. Du erinnerst dich vage daran, dass es sich um einen Mord handelte, der am 15. Januar 2018 in SQL City stattfand. Beginne damit, den entsprechenden Tatortbericht aus der Polizeidatenbank abzurufen.

Erkunden der Datenbankstruktur

Erfahrene SQL-Benutzer können Abfragen nutzen, um die Struktur einer Datenbank zu ermitteln. Jedes Datenbanksystem verwaltet diese Informationen unterschiedlich. Das SQL Murder Mystery basiert auf SQLite. Nutze diesen SQL-Befehl, um die Tabellen zu finden.

Neben den Tabellennamen musst du wissen, wie jede Tabelle aufgebaut ist. So machst du das mit SQLite.
