SQL Murder Mystery

SQL Murder Mystery は、架空の殺人事件を解決しながら SQL 言語を楽しく学び実践できるインタラクティブな推理ゲームです。目撃者の証言、人物、場所、さまざまな手がかりが含まれるデータベースを活用し、プレイヤーはデータをクエリして真犯人を突き止めます。

目的は、SQL クエリを駆使して捜査を進めることです。情報の検索、結果のフィルタリング、複数テーブルの結合、データの分析を通じて事件の全貌を再現し、殺人犯を特定します。

このプロジェクトは、SQL の学習、論理的思考、謎解きを没入感のあるゲーム形式で融合させています。SELECT、WHERE、JOIN、ORDER BY、GROUP BY、サブクエリなどの基本概念を身につけるための優れた演習となります。
