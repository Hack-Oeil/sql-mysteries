SQL Murder Mystery

SQL Murder Mystery es un juego de investigación interactivo que permite aprender y practicar el lenguaje SQL mientras se resuelve un caso de asesinato ficticio. Utilizando una base de datos que contiene testimonios, personas, ubicaciones y diversas pistas, el jugador debe consultar los datos para encontrar al culpable.

El objetivo es llevar a cabo la investigación mediante consultas SQL: buscar información, filtrar resultados, unir varias tablas y analizar los datos para reconstruir los eventos e identificar al asesino.

Este proyecto combina el aprendizaje de SQL, la lógica y la resolución de enigmas en un entorno lúdico e inmersivo. Constituye un excelente ejercicio para familiarizarse con conceptos esenciales como SELECT, WHERE, JOIN, ORDER BY, GROUP BY y subconsultas.
