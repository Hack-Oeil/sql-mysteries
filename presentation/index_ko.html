SQL Murder Mystery

SQL Murder Mystery는 가상의 살인 사건을 해결하면서 SQL 언어를 배우고 연습할 수 있는 대화형 추리 게임입니다. 목격자 진술, 인물, 장소, 다양한 단서가 포함된 데이터베이스를 활용하여 플레이어는 데이터를 쿼리하여 진범을 찾아내야 합니다.

목표는 SQL 쿼리를 사용하여 수사를 진행하는 것입니다. 정보 검색, 결과 필터링, 여러 테이블 조인 및 데이터 분석을 통해 사건의 전말을 재구성하고 범인을 밝혀냅니다.

이 프로젝트는 흥미진진한 몰입형 환경에서 SQL 학습, 논리력 및 퍼즐 해결을 결합합니다. SELECT, WHERE, JOIN, ORDER BY, GROUP BY 및 서브쿼리와 같은 필수 개념을 익히기에 훌륭한 실습 과제입니다.
