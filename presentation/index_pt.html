SQL Murder Mystery

SQL Murder Mystery é um jogo investigativo interativo projetado para aprender e praticar a linguagem SQL enquanto se resolve um caso fictício de homicídio. Utilizando um banco de dados com depoimentos de testemunhas, pessoas, locais e várias pistas, o jogador deve consultar os dados para encontrar o culpado.

O objetivo é conduzir a investigação por meio de consultas SQL: pesquisar informações, filtrar resultados, associar várias tabelas e analisar dados para reconstituir os acontecimentos e identificar o assassino.

Este projeto combina a aprendizagem de SQL, raciocínio lógico e resolução de enigmas em um ambiente lúdico e imersivo. É um excelente exercício para se familiarizar com conceitos essenciais como SELECT, WHERE, JOIN, ORDER BY, GROUP BY e subconsultas.
