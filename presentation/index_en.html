SQL Murder Mystery

The SQL Murder Mystery is an interactive detective game designed to teach and practice SQL while solving a fictional murder case. Using a database containing witness testimonies, people, locations, and various clues, players must query the data to find the culprit.

The goal is to conduct the investigation using SQL queries: search for information, filter results, join multiple tables, and analyze data to reconstruct events and identify the murderer.

This project combines SQL learning, logic, and puzzle-solving in a fun, immersive environment. It serves as an excellent exercise for getting familiar with essential concepts such as SELECT, WHERE, JOIN, ORDER BY, GROUP BY, and subqueries.
