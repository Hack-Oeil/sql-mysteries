SQL Murder Mystery

SQL Murder Mystery 是一款互动式侦探推理游戏，玩家可以在侦破一起虚构谋杀案的同时学习并练习 SQL 语言。利用包含目击者证词、人物、地点和各种线索的数据库，玩家需要查询数据以找出真凶。

目标是通过 SQL 查询进行案件调查：检索信息、筛选结果、关联多张数据表并分析数据，从而还原案发经过并锁定凶手。

该项目将 SQL 学习、逻辑推理和解谜巧妙融合在一个引人入胜的趣味体验中，是掌握 SELECT、WHERE、JOIN、ORDER BY、GROUP BY 以及子查询等核心概念的绝佳实践练习。
