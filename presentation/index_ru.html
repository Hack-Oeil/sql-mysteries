SQL Murder Mystery

SQL Murder Mystery — это интерактивная детективная игра, позволяющая изучать и практиковать язык SQL в процессе расследования вымышленного убийства. Используя базу данных, содержащую показания свидетелей, сведения о людях, местах и различные улики, игрок выполняет запросы к данным, чтобы найти преступника.

Цель — провести расследование с помощью SQL-запросов: искать информацию, фильтровать результаты, объединять таблицы и анализировать данные, чтобы восстановить картину событий и установить личность убийцы.

Этот проект сочетает в себе обучение SQL, логику и решение головоломок в увлекательном игровом формате. Это отличное практическое упражнение для освоения ключевых понятий: SELECT, WHERE, JOIN, ORDER BY, GROUP BY и подзапросов.
