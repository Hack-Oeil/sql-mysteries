SQL Murder Mystery

SQL Murder Mystery คือเกมสืบสวนเชิงโต้ตอบที่ช่วยให้คุณได้เรียนรู้และฝึกฝนภาษา SQL ไปพร้อมกับการไขคดีฆาตกรรมจำลอง โดยใช้ฐานข้อมูลที่ประกอบด้วยคำให้การของพยาน ข้อมูลบุคคล สถานที่ และเบาะแสต่างๆ ผู้เล่นต้องเขียนคำสั่งค้นหาข้อมูลเพื่อตามหาตัวคนร้าย

เป้าหมายคือการดำเนินการสืบสวนด้วยคำสั่ง SQL: ค้นหาข้อมูล กรองผลลัพธ์ เชื่อมโยงหลายตาราง และวิเคราะห์ข้อมูลเพื่อปะติดปะต่อเหตุการณ์และระบุตัวฆาตกร

โปรเจกต์นี้ผสมผสานการเรียนรู้ SQL การคิดเชิงตรรกะ และการไขปริศนาเข้าด้วยกันในรูปแบบที่สนุกสนานและน่าติดตาม นับเป็นแบบฝึกหัดที่ยอดเยี่ยมในการทำความเข้าใจคำสั่งสำคัญ เช่น SELECT, WHERE, JOIN, ORDER BY, GROUP BY และ Subquery
